---
name: Live insight card structure
description: How read-only brain-core ledger insights should follow the shared agent-card design without inventing decision content.
---

Read-only ledger insights use the shared proposal-card primitives and visual rhythm: agent header, hero, labeled sections, key facts, evidence, confidence/trend, technical detail, and pager when applicable.

**Why:** the Figma agent card is the product-wide visual standard, but ledger insights do not have proposal decisions or supported “what happens next” actions.

**How to apply:** reuse the shared card sections and spacing, rename decision-oriented copy to honest observational language such as “Why This Matters,” and never add Approve, Reject, Acknowledge, fabricated warnings, or unsupported evidence links.
